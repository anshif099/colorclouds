# Colorclouds B2B Website

A responsive, premium static website retaining Colorclouds' cream, purple, pink, blue, yellow and green palette.

Open `index.html` in a browser or serve this folder with any static web server. No build step or dependencies are required.

## Features
- Responsive navigation, active section links and back-to-top control
- Local learning photography, floating hero elements and scroll reveal animations
- Ecosystem category filters and context-aware partnership links
- Accessible FAQ accordions and a validated partnership enquiry form
- Reduced-motion support, keyboard focus states and skip navigation

## Enquiries
The form opens a prepared email draft addressed to hello.colorcloudslearning@gmail.com. The visitor sends it through their email app. There is no server-side form delivery or data storage.

## Assets
Learning photographs are downloaded from Unsplash and stored in `assets/learning-1.jpg` through `learning-6.jpg`. The original Colorclouds logo is retained. Google Fonts supplies Manrope and DM Sans; system sans-serif fonts are used when unavailable.
